# Pipro Robot

Pipro Robot 是一套基于 ROS 2 的移动盘点与取送机器人软件。它把地图导航、货架盘点、按单取货、平台交付和库存管理串成一条任务流程，并提供网页和语音两种交互入口。

- [项目介绍、代码框架与依赖说明](项目说明.md)
- [功能包源码](src/)

仓库中的配置已脱敏，本版删除了私有配置的config与相关yaml文件。模型、地图、设备参数和凭据需自行准备。机械臂几何与关节参数也已移除，补齐并核对前，任务管理包会阻止编译。请先阅读项目说明，再配合我们的复刻方法进行构建或连接实机。

感谢 ROS 2 及相关开源项目的开发者和维护者。丰富的开源工具、文档与社区经验，为本项目的环境感知、导航、交互、任务开发和性能优化提供了巨大帮助。
